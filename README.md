## 🚀 Sobre o Projeto

Este projeto é uma página web inspirada na Nike, focada em performance, design limpo e ótima experiência do usuário. Ele conta com suporte nativo a temas (Claro e Escuro) e interações dinâmicas sem a necessidade de frameworks pesados de JavaScript.

---

## ✨ Recursos

* **Alternância de Tema (Dark/Light):** Botão interativo para alternar o esquema de cores da página em tempo real.
* **Troca Dinâmica de Logo:** A logo da marca adapta-se automaticamente para garantir visibilidade perfeita nos modos claro e escuro.
* **Modal de Visualização Rápida (`<dialog>`):** Janela flutuante interativa ao clicar nos tênis, permitindo ver detalhes e escolher tamanhos sem sair da página.
* **Tabela de Tamanhos Completa:** Conversão de numerações (BR, US, EUR e CM) integrada nas dúvidas frequentes.
* **Design Responsivo:** Totalmente adaptado para computadores, tablets e telemóveis graças à grid fluida do Pico.css.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias web nativas e modernas:

* **HTML5:** Estrutura semântica da página.
* **CSS3 / Pico.css (v2):** Framework CSS minimalista baseado em classes semânticas e variáveis nativas.
* **JavaScript (Vanilla):** Lógica para manipulação do DOM, troca de temas e controle de modais.
